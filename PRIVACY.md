# boomrng Privacy Policy

Last updated: May 4, 2026

boomrng is a Chrome extension for blocking distracting websites, applying optional timed locks, and limiting open tabs.

## What data boomrng stores

boomrng stores the following data locally in Chrome extension storage on your device:

- blocked sites and optional timer settings
- allowed sites
- redirect URL
- max tab limit
- optional local PIN lock

## What browsing data boomrng uses

boomrng checks page URLs and tab counts locally in the browser so it can:

- block or redirect sites you configured
- apply timed locks to sites you configured
- enforce your tab limit
- show countdown and status information in the popup

boomrng does not upload your browsing activity to a remote server.

## Data sharing

boomrng does not sell, transfer, or share personal data with third parties.

boomrng does not use analytics, advertising SDKs, or remote user tracking in this version.

## Accounts

boomrng does not require an account in this version.

The optional PIN lock is stored locally in your browser profile and is not synced to a remote backend.

## Data deletion

You can delete boomrng data by:

- removing or changing settings inside the extension
- resetting the local PIN lock from the extension UI
- uninstalling the extension
- clearing the extension's stored data in Chrome

## Contact

For questions about this privacy policy, contact the boomrng publisher through the Chrome Web Store listing or repository associated with the extension.
